# Python Practice Exercises

Solutions to beginner exercises from [Practice Python](https://www.practicepython.org/), 
solved while strengthening Python fundamentals for my data analysis coursework.

## About
Each exercise focuses on a core Python concept — loops, functions, lists, 
dictionaries, file handling, and error checking. Solving these helped me 
build the fundamentals I'm now applying in data analysis (pandas, cleaning 
data, working with files and structured data).

## Structure
- `exercise01_character_input.py`
- `exercise02_odd_or_even.py`
- ... (one file per exercise)

## What I learned
- Working with strings, lists, and dictionaries
- Writing reusable functions
- Basic file I/O and error handling
- Debugging and testing small scripts

## Note
These are practice/learning exercises, not original problems — credit to 
[practicepython.org](https://www.practicepython.org/) for the exercise prompts.
